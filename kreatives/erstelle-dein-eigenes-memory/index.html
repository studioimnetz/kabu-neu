Erstelle dein eigenes Memory

Spielst du auch so gerne Memory wie KABU? Dann ist der heutige Beitrag etwas für dich! Gemeinsam mit einer Kinderredaktion haben wir unser eigenes Gedächtnisspiel erstellt! In diesem Beitrag zeigen wir dir, wie du dein eigenes Memory erstellen kannst! Du benötigst dafür nur vier einfache Schritte!

Das brauchst du alles für dein Memory:

  • Schere
  • Klebestift
  • Karton oder dickeres Papier (z. B. Fotokarton)
  • Ein Smartphone oder Tablet mit einer Collagen App
  • Einen Drucker

![Bild](/images/202385_Bild 1.jpg)

Wir haben für unser Memory noch ein Mikroskop verwendet.

1. So gehts:

Wenn du möchtest kannst du dir ein Thema für dein Memory überlegen. Du kannst zum Beispiel alle Gegenstände in deiner Lieblingsfarbe fotografieren.

Natürlich kannst du auch ein und denselben Gegenstand aus unterschiedlichen Blickwinkeln fotografieren. Also zum Beispiel so wie ein Frosch den Gegenstand sehen würde und anschließend aus der Sicht eines Vogels!

In unserem Fall hat sich die Kinderredaktion für ein Mikroskop entschieden. Die Kinder haben den selben Gegenstand einmal mit dem Mikroskop und anschließend mit der normalen Kamera fotografiert!

Konntest du die Paare gleich erkennen?

![Bild](/images/202385_Bild 12.jpg)

2. Vorlage erstellen

In einer Collagen App kannst du nun eine Vorlage auswählen, die beispielsweise sechs gleichgroße Bilder hat! Füge nun deine Bilder in die Vorlage ein! Frage hier am Besten deine Eltern um Hilfe, wenn du keine CollagenApp kennst.

3. Drucken

Bei einem klassischen Memory kannst du nun deine Vorlage zwei Mal ausdrucken! Hast du dich für eine andere Art entschieden, wie zum Beispiel bei den unterschiedlichen Perspektiven - dann reicht es, wenn du diese einmalig ausdruckst!

Wenn du nicht weißt, wie du die Bilder von deinem Tablet und/oder Smartphone ausdrucken kannst, dann frage eine erwachsene Person um Hilfe!

4. Ausschneiden und Kleben

Jetzt bist du schon beim letzten Schritt! Schneide die Bilder aus und klebe diese anschließend auf einen dickeren Karton und/oder Fotokarton! Achte darauf, dass alle Bilder die selbe Größe haben!

FERTIG! Nun kannst du auch schon loslegen!
